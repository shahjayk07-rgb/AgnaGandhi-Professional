# Local website test

1. Extract the ZIP.
2. On Windows, double-click `start-local.bat`. On macOS/Linux, run `bash start-local.sh` from this folder.
3. Open `http://127.0.0.1:8000` in your browser.
4. Test navigation, mobile layout, all article links, the nine-click About interaction, enquiry form behaviour and analytics configuration.
5. Press Ctrl+C in the terminal to stop the server.

Google Analytics stays inactive until a real GA4 Measurement ID is configured in `site-config.js`. Do not use a placeholder ID.
