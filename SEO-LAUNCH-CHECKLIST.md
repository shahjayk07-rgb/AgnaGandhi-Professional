# SEO / AEO / AI-search launch checklist

## Included in this package
- Unique page titles and meta descriptions for every HTML page.
- Canonical URLs using `https://agnagandhi.in/`.
- Open Graph and Twitter preview metadata plus an OG image.
- JSON-LD `WebSite`, `WebPage`/`ProfilePage`/`Article`, and `Person` structured data.
- `robots.txt` and `sitemap.xml`.
- Crawlable internal links and informational article pages.

## Before publication
1. Confirm the domain's preferred canonical version (non-www is currently configured) and redirect HTTP / www to HTTPS / non-www at hosting/DNS layer.
2. Verify all professional details, practice scope and links with Agna.
3. Have the website and enquiry approach reviewed for compliance with applicable Bar Council of India professional-conduct rules. Do not add claims such as "best lawyer", guarantees, rankings, testimonials, or solicitation-oriented language.
4. Validate structured data using Google's Rich Results Test and Schema Markup Validator.
5. Set up Google Search Console and Bing Webmaster Tools; verify domain ownership.
6. Submit `https://agnagandhi.in/sitemap.xml` to Search Console and Bing Webmaster Tools.
7. For Bing, consider IndexNow after launch and submit changed URLs.
8. Test mobile usability, accessibility, page speed, HTTPS, all links, robots.txt, canonical URLs, and sitemap availability.
9. Measure indexing and queries in Search Console and Bing Webmaster Tools after launch; update content based on real query data.

## Strategy
Build relevance through accurate identity/profile information and a small set of genuinely useful, carefully reviewed educational pages. Do not create dozens of near-duplicate pages for synonyms, locations or keywords. Search engines and AI answer systems do not guarantee inclusion or rankings. Schema helps explain content; it does not guarantee rich results or AI citations.

## Important limitation
This is a static website. Search console verification, hosting redirects, indexing requests, email setup, legal review and ongoing performance monitoring still need to be completed by the site owner.
